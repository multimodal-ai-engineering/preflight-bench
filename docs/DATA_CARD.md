# Data card: PreflightBench-Live (full study, v1 candidate)

**What it is.** Pairs of screenshots from synthetic web pages that keep moving, for testing checks an agent runs right before it acts: is the planned click still good (`settled`), is a dialog in the way (`dialog`), and did the last action work (`worked`). Generated by `generator/make_full.py` from `pages_full/` after the preregistration tag `prereg-v1`.

**Content.** Six page kinds, each with four layout variants: a static booking form (Tier 0, the control) and five pages that move by design (Tier 1): a market dashboard with fictional symbols, a news feed that inserts items at the top, a shared notes document with a second user typing, a panning map with procedurally drawn tiles, and a canvas whiteboard. Tier 2 replays Tier 0/1 screens through a remote-desktop degrader (100–500 ms delay, partial repaints, scaling, JPEG). All names, places, symbols, outlets and text are invented; the designs are generic and imitate no real product. No personal data. No network content: every page is a local, self-contained HTML file.

**Pairs.** Action pairs: two planning frames 200 ms apart, two current frames 200 ms apart 6.5 s later, the target's planned box and click point, and (dev, or private for test) the truth from the page: whether the planned click still lands, the target's box, a 4 px hit mask, look-alikes, dialogs, at nine moments after the current frame. Worked pairs: frames before and 6.7 s after a click, two frames each, the planner's one-sentence expected effect, and where that effect would appear.

**Splits.** By template: variants 0–1 are dev (public, with labels), variants 2–3 are test (labels in `private/`, scored by `bench/score.py`). IDs are opaque.

**Labels.** From the DOM and the canvas's render state at the current frame, never from the seeded event's name. Background motion near and away from the target, a second event after the current frame in 25% of pairs.

**Known properties.** On the canvas page, the board's own motion never moves the canvas targets (only seeded events do). Low motion on the notes page can leave a 200 ms window unchanged. Rendering is deterministic for a given Chromium build (Playwright 1.64.1, Chromium build 1248, software raster); other builds may differ by font rendering.

**License.** Data CC BY 4.0, code MIT. Released with the paper; regenerate with `generator/make_full.py` (see the README).

**Separate, not part of the benchmark.** A read-only real-site set (public pages, no clicks) is collected for an in-the-wild comparison. It contains third-party content, is never released and never pooled.
